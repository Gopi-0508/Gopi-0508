## Academic Projects

> Small projects I built while learning — nothing fancy, just practice.

**Linear Algebra in Python**
Implemented LU Decomposition, QR Decomposition, Eigenvalues and Eigenvectors, and Matrix Inverse from scratch using NumPy. The goal was to understand the maths behind ML, not just call library functions.

**Linear Regression Practice**
Built univariate and multivariate linear regression using scikit-learn. Learned about train/test splits, cost functions, and model evaluation.

**Basic REST Web Project**
A simple front-end project in HTML and CSS that fetches data from a REST API. My first step toward building web applications.
